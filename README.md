# Portafolio de Data Analytics

Este portafolio reúne proyectos prácticos de análisis de datos utilizando **Power BI, R, Python y SQL**.  
Su objetivo es mostrar habilidades en:

- **Visualización ejecutiva de KPIs** con Power BI  
- **Modelado y análisis estadístico** en R y Python  
- **Consultas y manejo de bases de datos** con SQL  
- **Documentación clara y orientada a negocio**

Incluye casos de estudio como ventas de videojuegos y detección de fraude en tarjetas de crédito, diseñados para demostrar impacto real en la toma de decisiones empresariales.
