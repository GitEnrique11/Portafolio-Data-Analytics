# Credit Card Fraud – R

El modelo de regresión logística identifica que ciertas variables (V4, V21, V22) incrementan el riesgo de fraude, mientras que otras (V8, V10, V14, V20, V27, V28) lo reducen.
La variable Amount apenas roza significancia, pero no aporta evidencia fuerte.

En términos de desempeño:

Precisión global (Accuracy): 99.9%

Sensibilidad (legítimos detectados): ~100%

Especificidad (fraudes detectados): ~56%

Balanced Accuracy: 77.8%

El modelo es altamente confiable para identificar transacciones legítimas, pero su capacidad para detectar fraudes sigue siendo moderada.
